PRIVACY

Local by default.

Effective 2026-07-18.

What stays local

Transcripts, source code, profiles, indexes, local guards, and detailed firing logs stay on your machine. Presidio and Gitleaks run locally before model-assisted scanning. Scrub failure stops the scan.

Optional anonymous events

Nothing is sent without opt-in. Accepted fields are limited to onboarding choices, returning-session action categories, scrubbed incident patterns, guard-fired agents, and doctor-health status.

The endpoint rejects transcripts, source-like text, secrets, email addresses, and local paths. VibeBloat stores no account, device ID, IP address, user agent, or raw request header. Vercel and Supabase still process network metadata under their own policies.

Anonymous rows have no stable user identifier, so a specific prior row cannot be located. Disable opt-in to stop future events.

Delete local data

vibebloat email --forget removes local email capture. vibebloat uninstall --yes removes VibeBloat-owned integrations and local data. --keep-data preserves local guard homes and audit data.

Community contributions

GitHub pull requests use GitHub identity and history. Request removal through the repository issue tracker and link the contribution.
